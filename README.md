# Milestone 1 CIE – Spotify Data Analysis

**USN:** 4SF25CI062  
**Section:** 3B

## 1. Project Overview

This project focuses on analysing the Spotify dataset using Python and Pandas. The main objective is to perform data transformation, handle missing values, generate useful insights, and visualize the results.

## 2. Dataset Description

The dataset contains Spotify track information, including:

- Track names and artists
- Album names
- Track popularity
- Song duration
- Music genres
- Audio features such as danceability, energy, acousticness and tempo

## 3. Tools and Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 4. Project Tasks Performed

1. Imported and explored the Spotify dataset.
2. Checked dataset dimensions, column names and data types.
3. Removed unnecessary columns.
4. Identified and removed duplicate records.
5. Converted song duration from milliseconds to minutes.
6. Identified and handled missing numerical values using mean imputation.
7. Analysed popular songs, music genres and artists.
8. Calculated average song duration, danceability and energy.
9. Created visualizations to understand the dataset.

## 5. Visualizations

The following visualizations were created:

- Top 10 Most Popular Songs
- Top 10 Most Popular Music Genres
- Distribution of Song Duration
- Relationship Between Danceability and Energy

## 6. Files Included

- `CIE1.ipynb` – Jupyter Notebook containing the Python code, analysis and visualizations.
- `spotify_tracks.csv` – Spotify dataset used for the analysis.

## 7. Conclusion

The project demonstrates how Python and its data analysis libraries can be used to clean, transform, analyse and visualize real-world datasets. The analysis helped identify patterns in song popularity, music genres and audio features.

This project provided practical experience in data preprocessing, handling missing values, generating insights and creating visual representations of data.
